## 2.1 Пропуски (Missing Values / NULL)

Для каждого столбца определить:

- [ ] количество пропусков;
- [ ] процент пропусков.

После этого исследовать:

- [ ] насколько эти поля важны;
- [ ] мешают ли пропуски анализировать продажи;
- [ ] мешают ли анализировать клиентов;
- [ ] отличаются ли строки с пропусками от остальных.

Вопросы себе:

**Что я потеряю, если удалю эти строки?**

**Можно ли использовать такую строку для анализа продаж, даже если нельзя использовать для анализа клиентов?**

**Не исказит ли удаление этих строк результаты?**

Не использовать правило:

`есть NULL → удалить строку`.

## 2.2 Дубликаты (Duplicates)

Проверить:

- [ ] полностью одинаковые строки;
- [ ] повторяющиеся комбинации заказ + товар;
- [ ] повторяющиеся идентификаторы;
- [ ] одинаковые операции, произошедшие примерно одновременно.

Главный вопрос:

> **Что именно в этом датасете должно считаться дубликатом?**

Не удалять строку только потому, что Python назвал её duplicate.

Две одинаково выглядящие строки теоретически могут быть двумя реальными операциями.
